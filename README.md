# 📊 Система финансового мониторинга и учета (ФЗ)

Инструмент автоматизации расчетов и учета финансовой задолженности студентов. Проект разработан для исключения ошибок при ручной обработке данных, ускорения подготовки отчетности и обеспечения фокуса на актуальных задачах.

![Интерфейс системы финансового мониторинга](https://github.com/UzunovaLizaveta312/financial-monitoring-system/commit/d4424c0e9fb25c8a9dc6342cbea9d038c136f91c)

## 🛠 Функциональные возможности и логика работы
* **Связанные массивы данных:** Настроена синхронизация информации между рабочими листами (5+ листов) с использованием функций `ВПР` (`VLOOKUP`). Данные динамически подтягиваются в зависимости от выбранного периода.
* **Автоматизация расчетов:** Применение агрегирующих функций (`СУММЕСЛИ` / `SUMIFS`) для создания сводной аналитики по кураторам и типам задолженностей (техническая/реальная).
* **Динамическое управление видимостью:** Внедрен механизм визуальной фильтрации данных за прошедшие периоды. Это позволяет кураторам фокусироваться исключительно на текущих дебиторах и повышает производительность работы.
* **Smart-администрирование:** Функция автоматической подстановки ФИО ответственного куратора в зависимости от параметров студента.
* **Визуальный контроль:** Настроено цветовое кодирование статусов (условное форматирование) для быстрого считывания информации.

## 🚀 Технологический стек и методология
* **Инструмент:** Google Таблицы / MS Excel.
* **Методология:** Автоматизация рутинных бизнес-процессов, работа с динамическими массивами, защита и деперсонализация данных.

## 💡 Результаты внедрения
1. Полное исключение «человеческого фактора» при пересчете финансовых показателей.
2. Повышение скорости формирования отчетности в 3 раза.
3. Удобная масштабируемость системы под растущий контингент студентов.
